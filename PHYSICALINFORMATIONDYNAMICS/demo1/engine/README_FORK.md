# demo1/engine: the PID fork of gen3 (Demo 1, brief `02_DEMO1_BRIEF.md`)

- **Source.** `edmd_gen3.c`, `edmd_gen3.h` and `edmd.h` were copied from `hspist3/edmd_core/` at origin/main `6b29aa5b`. Each file's 4-line header gives that file's last change (`a71f394d` for gen3, `942c3b63` for `edmd.h`; provenance only, brief §8) and its source blob: `edmd_gen3.c` `e7d9ce3e`, `edmd_gen3.h` `6616f999`, `edmd.h` `4ccd5da0`. The blob is the identity; `make test` (test 2) has git confirm it.
- **1a** was the originals plus the header (original line n = fork line n + 4). **1b** changes `edmd_gen3.c` and `.h` only; every changed hunk adds a line opening with `/* PID: ` (test 2, pre-check B21). `edmd.h` stays byte-identical below its header, because the unmodified `edmd.c` is compiled against the original.
- **gen2 is not forked.** The M1/M2 harnesses' run D needs `hspist3/edmd_core/edmd.c` (blob `b9921b0f`), so both sides of the box reference link the same unmodified object, `bin/gen2.o`. Brief §2 rule 8 is read as: fork gen3 and original gen3 are never in one binary.
- **Compiler exemptions** (`Makefile`; pre-check A1, A2), identical on both sides. gcc only: `-Wno-format-truncation` for gen3 (original line 842). gen2: `-D_DEFAULT_SOURCE`, plus `-Wno-misleading-indentation` under gcc.
- **Static walls (1b).** `edmd3_set_walls` takes closed loops of segments (lumen on the left) and arcs (lumen inside, counter-clockwise), checked closed to 1e-6 px. New event types `T_SEG` = 6 and `T_ARC` = 7 come after the original ones, so box-only runs order their events as before. Segment: line or endpoint contact, the earlier one. Arc: hit from inside only, the larger root of the eroded circle (radius r − R) in a cancellation-free form, the unwrapped angle test, arcs with r ≤ R skipped (pre-check B2/B3). The last primitive hit is kept in `Disk3.last` as `-2 - NOBJ - p`. Each cell lists the primitives within R + 2 tol_wall; a cell crossing predicts only the newly reachable ones.
- **The detectors cover the walls.** The validator (local and full checks; signed distance with vertex pseudo-normals, repair by reflection), the schedule audit (a brute-force rebuild of every disk's earliest wall event; a time difference beyond 1e-10 of the horizon is an error only if v_n |dt| > tol_face, else a grazing approach that agrees to rounding, counted as `prim_dt_cond`), the contact audit (`edmd3_contact_audit_prims`, gaps against tol_face) and the ledger (`J_prims`, per-primitive impulse in `edmd3_prim_impulse`). New fields go at the end of the public structs and `EDMD3_NCLS` stays 5 (pre-check B8), so the box reference's record prefixes stay comparable.
- **Kept as they were (brief §8, B7).** The collision-hook statics. `edmd3_checkpoint_write` refuses (returns 0) once walls are set, and `edmd3_checkpoint_read` refuses into a state with walls; with no walls both are unchanged.
- **Test 3** (`make test`) compares the fork, walls unused, with the original byte for byte: M1/M2 harnesses and `tests/box_final_state.c` (final states, records, hook, checkpoint restart, event log, accessors); the bytes 1b appends to the records print on `tail` lines that must be zero. `prim_tests empty` shows that an empty wall list changes nothing.
- **Positive controls (test 10).** `tests/prim_controls.c` includes this `.c` with `-DPID_WHITEBOX`, which alone compiles in `pid_plant_reflect_sign`; it plants a deleted wall event, a disk 0.1 R through a segment, a flipped reflection and a wall event moved by 1e-3 time units (its baseline: a disk grazing a 30° wall, which must not count as an error), and each must be reported.
- **Users of the walls.** `tests/prim_tests.c` (tests 4–6: corridor, tilted corridor, Y junction), `tests/prim_controls.c` (test 10) and `pid_demo1.c` (brief §5; tests 7–9 on the Demo 0 hull). Next: 1c on the Mac (viewer, one PNG).
