### Item 3: plan only, not run -- validating the accelerated backend (--edmd-acc=1)

Byte identity is not the test. An accelerated event scheduler processes events in a different order, and hard-disk dynamics is chaotic, so two backends diverge trajectory by trajectory however correct both are. The test is therefore statistical, on the same seeds: run three cells that span the campaign -- (eta = 0.10, N = 400), (eta = 0.30, N = 900), (eta = 0.65, N = 400) -- with 5 masses x 25 seeds on each backend, drift-first, 37.5 periods. Record the wall-time ratio per run: the backend is only interesting if it is 5-10x faster.
