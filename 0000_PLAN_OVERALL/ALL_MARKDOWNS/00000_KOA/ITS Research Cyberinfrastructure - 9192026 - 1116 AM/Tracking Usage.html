Tracking Usage

Each users is responsible for managing their own permanent storage and copying off or deleting files they no longer need.  This can also extend to koa_scratch in that users can delete temporary files sooner than the automated purge process, which in some cases can help reduce the chance that an emergency purge that will being to  look at files younger than 90 days will be required.

For users to see what they are using, a few commands are at your disposal, including one specific to Koa.

  • df - The df command can be used to see how much disk is free.  By default it shows you every disk on the system, but you can limit it to a give disk, making it target only the locations you care about.  Do note, that df  is not meant to show your specific usage, but due to how storage is allocated on Koa, it can be used to show the usage of common locations.
    [itsrci@vn-00-00-00 ~]$ df -h /home/itsrci /mnt/lustre/koa/scratch/itsrci
Filesystem                                               Size  Used Avail Use% Mounted on
home-ib.mana.ci.its.hawaii.edu:/manastore/home/itsrci     50G  1.0M   50G   1% /home/itsrci
10.200.2.20@o2ib100,10.200.2.21@o2ib100:/koa             800T  451T  350T  57% /mnt/lustre/koa

  • du - The du command can be used to determine disk usage.  This command can take a while, especially if you have a lot of files in the location you are trying to figure out the usage for.  While this can provide the exact usage in a location, it may not be recommended to run this repeatedly as you are working with a a network file system on Koa, making the look up for space usage expensive.
    [itsrci@vn-00-00-00 ~]$ du -sh .[^.]* ~/*
512     .bash_logout
1.0K    .bash_profile
1.0K    .bashrc
512     .condarc
1.0K    .config
1.0K    .emacs
14K     .local
3.5K    .ssh
512     .vimrc
21K     /home/itsrci/examples
512     /home/itsrci/koa_scratch

  •   usage - On Koa a command was created just simply named usage.  This command is designed to know what storage locations you have access to and ti display the usage for all these and to also provide you an approximate  value for your usage for those locations that usage may not be all due to your, e.g., koa_scratch, lab storage, class storage, KoaStore.  The approximate usage is updated at 1 hour intervals, but can take longer to be reflected due to how changes are tracked. The output of this command is also provided as you login to Koa using SSH as part of the message of the day.
