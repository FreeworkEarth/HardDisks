Simplifying Your Koa Data Transfers

Moving large amounts of data to and from the Koa cluster requires the right tools for the job. For the fastest and most reliable transfers, especially for large datasets, it is highly recommended to use Koa's dedicated Data Transfer Node (DTN).

Why Use the Data Transfer Node?

The standard login nodes (koa.its.hawaii.edu) are protected by a firewall that can significantly slow down large data transfers. The DTN is a dedicated machine designed to bypass this firewall, enabling much faster and more efficient data movement.

Which Transfer Method Should I Use?

Koa offers two primary methods for using the DTN, each suited for different needs.

How to Connect and Transfer Data

1. Standard Shell Tools (scp, rsync, sftp)

This method is best for routine, manual file transfers. Use this specific address instead of the normal Koa login address.

  • DTN Address: koa-dtn.its.hawaii.edu

Example (using scp from your local computer):

# Copy a local file TO your home directory on Koa
scp local_file.dat your_username@koa-dtn.its.hawaii.edu:~/

# Copy a file FROM Koa TO your current local directory
scp your_username@koa-dtn.its.hawaii.edu:~/path/to/remote_file.dat .

2. Globus Web Platform

This is the most powerful and reliable method for very large or critical data transfers. Globus automatically retries failed transfers and notifies you upon completion.

  • Globus Collection Name: UH Koa Collection

To use Globus, log in to the Globus web portal, search for the UH Koa Collection, and initiate transfers between it and other Globus collections (including your own personal computer after installing Globus Connect Personal).

Koa documentation on Data Transfer

The DTN is for data transfer only.

  • ✅ You can access all your Koa files (home, lab, scratch), just like on a login node.

  • ❌ You cannot submit or run computational jobs from the DTN.
