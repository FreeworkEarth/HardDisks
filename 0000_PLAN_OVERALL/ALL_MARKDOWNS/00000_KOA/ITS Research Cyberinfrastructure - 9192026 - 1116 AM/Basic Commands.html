Essential Slurm Job Commands

You only need to know a few key commands to manage your jobs on Koa. They fall into two main categories: Batch and Interactive.

1. Batch Jobs (Running a Script)

This is the most common way to run jobs on Koa. You write your commands into a script file and then submit it to the scheduler.

  • sbatch Purpose: Submits your job script to the queue. This is the main command you will use to start a job. Example: sbatch my_job_script.sh

  • scancel Purpose: Cancels a pending or running job. Example: scancel 12345 (where 12345 is your job ID)

2. Interactive Jobs (Working Directly on a Compute Node)

Use these commands when you need to work directly on a compute node for tasks like testing, debugging, or compiling software.

  • salloc Purpose: Allocates resources for a new interactive session. This is the recommended way to get a command prompt on a compute node. Example: salloc --ntasks=1 --cpus-per-task=4 --mem=16G --time=1:00:00

  • srun Purpose: While srun can start a simple interactive job, its main use on Koa is within a batch script to launch parallel tasks for applications like MPI.
