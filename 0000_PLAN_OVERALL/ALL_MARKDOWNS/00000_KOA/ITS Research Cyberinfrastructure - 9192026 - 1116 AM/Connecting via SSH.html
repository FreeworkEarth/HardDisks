Secure Shell (SSH)

The classic way to access remote systems like a lab server, or a HPC cluster is using a secure shell (SSH) client.  Clients come in a variety of packages.

  • Built into the command-line/terminal of your laptop/desktop operating system
    • ssh foo@koa.its.hawaii.edu
  • In a website in your browser (Open Ondemand web terminal)
  • Built in SSH client (Linux, MacOS, Windows 10+)
    • Windows https://www.hawaii.edu/askus/1874
  • A 3rd party software (Windows)
    • PuTTY (ITS instructions)

Usage

Koa's address for SSH: koa.its.hawaii.edu

SSH is command-line only and as such, knowing the command-line under Linux or MacOS is necessary to make optimal use of SSH and in some cases unlock all the functionality that Koa can provide.  If using the command-line is not something you have experienced or your have used the command-line, but feel your skills have become rusty, the following tutorials can be useful to get up to speed.
