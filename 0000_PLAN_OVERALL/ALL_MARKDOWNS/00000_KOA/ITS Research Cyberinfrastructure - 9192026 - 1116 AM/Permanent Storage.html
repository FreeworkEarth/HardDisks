Lab Storage on Koa

This optional storage is free permanent storage for your lab's sharing needs on the Koa cluster. 

At a Glance

What you get: 500 GiB of space
File Limit: 512,000 files and folders
Who can use it: Everyone in your lab that has an account on Koa
How many per lab: Only one storage space is provided per lab
Performance: High-speed, so your jobs run smoothly

📋 How to Get Lab Storage

Each lab can request one shared storage space.

  • To apply, fill out the request form: https://go.hawaii.edu/yDE

 

✅ Best Practices for Using Lab Storage

Follow these tips to avoid errors and keep your lab's space organized.

1. Check Your Usage

Your job can fail if you run out of space or exceed the file limit.

  • How to check: Run the usage command, or check the message that appears when you log in to Koa.

2. Organize Your Files

Since the space is shared, a clear structure prevents confusion.

  • We recommend:

    • Create a main folder for each user (e.g., /lab_storage/members/username_1/).

    • Create a separate folder for shared datasets or software (e.g., /lab_storage/shared_data/).

3. Manage Your File Count

You are limited by both total size (500 GiB) and the number of files (512,000). Having millions of tiny files can fill your quota even if you have plenty of storage space left.

Problem: Too many small files.
Solution: For small, read-only files, archive them into a single squashfs file. This special archive acts like a folder but only counts as one file. See the online documentation for instructions.

⚠️ Critical: You Are Responsible for Backups

The lab storage on Koa is NOT backed up. If data is accidentally deleted or lost, it cannot be recovered.

  • You must back up your own important files to a separate, external location.
    For source code, consider using a private GitHub repository.

For more information, please refer to our  online documentation.
