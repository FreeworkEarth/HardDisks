What is Open OnDemand?

Open OnDemand  (OOD) is a web portal that is used by many different institutions and is designed to ease the access for users of HPC systems.   

Access using OOD only requires an account on Koa and a web browser (on a smartphone, tablet, laptop, desktop, etc).  When accessing OOD using a device you do not have full control over (e.g., a desktop/laptop shared in the lab, or a desktop provided at the library) use of an incognito or private browser window is recommended, so that when you are done using OOD, closing the window will also log you out of Koa.

Connecting to Koa

In order to connect to Koa using OOD, one would navigate to https://koa.its.hawaii.edu and login using the UH login screen.

Features

Using OOD, a user would be able to:

  • Browse their files on Koa and even use a text editor to edit files 
  • Upload and download small files (less than 5 GB in size)
  • Perform basic file management (create and delete files)
  • Gain command-line/terminal access using the in browser SSH client
  • Run a series of applications enabled for users of Koa to utilizes
    • Jupyter Lab and Notebook
    • Rstudio Server
    • Matlab
    • Remote Desktop
