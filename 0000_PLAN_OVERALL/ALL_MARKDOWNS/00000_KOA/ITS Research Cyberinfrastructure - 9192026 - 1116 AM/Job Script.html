How to Create a Slurm Job Script

A job script is a simple text file that tells the Slurm scheduler two things:

  1. What resources you need (e.g., how much time, CPU, memory).

  2. What commands to run (e.g., your scientific program).

On Koa, these are typically Bash shell scripts. You submit them using the sbatch command.

Anatomy of a Job Script

A job script has two main parts: the resource request section at the top, and the command section at the bottom.

Lines that start with #SBATCH are special directives that request resources from Slurm. Lines that start with a plain # are regular comments for human readers.

Annotated Example

Here is a basic job script with each line explained. You can use this as a template for your own jobs.

#!/bin/bash
# --- Resource Request Section ---
#
#SBATCH --job-name=my_first_job      # A descriptive name for your job
#SBATCH --partition=sandbox          # The partition (queue) to run on
#SBATCH --time=00:10:00              # Maximum runtime in HH:MM:SS
#SBATCH --cpus-per-task=1            # Number of CPU cores requested
#SBATCH --mem=4G                     # Amount of RAM needed (e.g., 4G, 8G, 16G)
#SBATCH --output=job_output_%A.out   # File to write standard output to (%A is the Job ID)
#SBATCH --error=job_error_%A.err     # File to write standard error to
# --- Optional: If not enabled and set, the working directory is set to the directory sbatch was executed from ---
##SBATCH --chdir=/path/to/your/work   # Set the working directory for the job
#
# --- Optional: Email Notifications ---
##SBATCH --mail-type=ALL             # Send email on job ALL events (BEGIN, END, FAIL)
##SBATCH --mail-user=your_email@hawaii.edu  # Email address for notifications
#
# --- Command Section ---
#
echo "Job started on $(hostname) at $(date)"

# Purge any existing modules and load the ones you need
module purge
module load toolchain/intel

# Your actual commands or program to run
./my_program --input data.txt

echo "Job finished at $(date)"

Tip: To activate an option that starts with ##SBATCH, simply remove one of the # symbols.

Common Parameters Explained

While there are many #SBATCH options (sbatch), you only need a few to get started.

Using Provided Sample Scripts

Koa provides several example job scripts in your home directory to help you get started. It's best to copy an example that matches your needs and then modify it.

cd ~/examples/slurm/
