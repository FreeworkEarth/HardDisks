Containerized Software on Koa 📦

On Koa, we use Apptainer (formerly known as Singularity) to run pre-packaged software in containers. This is similar to Docker, but it is designed for High-Performance Computing (HPC) environments.

Using Apptainer

  • Pre-packaged Software: Some software, like AlphaFold, is already available in containers for all users.

  • Creating Your Own Containers: You can create your own containers, but you'll need administrative rights on a separate system to build them.

Accessing Containers: You can download containers from places like Dockerhub or upload your custom containers to a location where Apptainer can access them on Koa.

For detailed instructions, refer to our Apptainer documentation.
